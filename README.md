# MenchGame

منچ بازی انلاین

## حالت‌های بازی

- **منچ:** قوانین و تعداد مهره‌های قابل تنظیم قبلی.
- **مار و پله:** ۲ تا ۶ بازیکن، هر نفر یک مهره، ورود به خانهٔ ۱ با شش و نوبت جایزه با هر شش. فرود روی ابتدای نردبان یا سر مار، مهره را جابه‌جا می‌کند. ایستادن روی مهرهٔ حریف در مقصد نهایی، آن را از بازی خارج می‌کند و حریف برای ورود دوباره باید شش بیاورد؛ آمار زدن مهره‌ها در همان گزارش مشترک با منچ ثبت می‌شود. رسیدن دقیق به خانهٔ ۱۰۰، بازی را با برد همان بازیکن تمام می‌کند؛ تاس بیشتر از مقدار لازم، حرکتی ندارد.

نوع بازی هنگام ساخت اتاق یا در تنظیمات لابی توسط میزبان انتخاب می‌شود و برای همهٔ اعضای اتاق ارسال می‌شود. هر دو حالت، آنلاین و روی یک دستگاه با بازیکن انسانی یا ربات قابل استفاده‌اند.

مسیرها و مختصات برد مار و پله در `src/utils/snakesAndLadders.ts` تعریف شده‌اند و بین منطق بازی، رسم برد و انیمیشن مشترک‌اند.

## اجرا

پروژه با React و Vite اجرا می‌شود:

```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار و پیش‌نمایش آن:

```bash
npm run build
npm run start
```

## تست

```bash
npm run test:rules
npm run test:snakes
npm run test:ui
```

تست قوانین مار و پله شامل ورود، تمام مارها و نردبان‌ها، برد، نوبت‌ها و همهٔ ۶۰۶ ترکیب موقعیت مهره و تاس است. تست مرورگر، حرکت دستی در هر دو مود، حرکت ربات‌ها، نمایش موبایل و هماهنگی و اتصال مجدد دو بازیکن آنلاین را بررسی می‌کند. تاس فقط داخل محیط تست مقدار مشخص می‌گیرد.

برای تست مرورگر به Node سازگار با Vite و SDK و runtime دات‌نت ۹ نیاز است. Playwright سرورهای محلی فرانت و بک را روی پورت‌های ۴۱۷۳ و ۵۴۱۷ اجرا و پس از تست متوقف می‌کند. مرورگر پیش‌فرض را با `npx playwright install chromium` نصب کنید، یا از Chrome موجود روی سیستم استفاده کنید:

```bash
PLAYWRIGHT_CHANNEL=chrome npm run test:ui
```

اگر فقط runtime دات‌نت ۱۰ موجود است، برای اجرای تست محلی روی آن می‌توان `DOTNET_ROLL_FORWARD=Major` را به همین دستور اضافه کرد؛ هدف پروژهٔ بک‌اند همچنان `net9.0` است.
