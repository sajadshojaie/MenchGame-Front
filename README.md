# MenchGame

منچ بازی انلاین

## حالت‌های بازی

- **منچ:** قوانین و تعداد مهره‌های قابل تنظیم قبلی.
- **مار و پله:** ۲ تا ۶ بازیکن، هر نفر یک مهره، ورود به خانهٔ ۱ با اولین شش و نوبت جایزه با هر شش. فرود روی ابتدای نردبان یا سر مار، مهره را جابه‌جا می‌کند. مهره‌ها یکدیگر را نمی‌زنند. رسیدن دقیق به خانهٔ ۱۰۰، بازی را با برد همان بازیکن تمام می‌کند؛ تاس بیشتر از مقدار لازم، حرکتی ندارد.

نوع بازی هنگام ساخت اتاق یا در تنظیمات لابی توسط میزبان انتخاب می‌شود و برای همهٔ اعضای اتاق ارسال می‌شود. هر دو حالت، آنلاین و روی یک دستگاه با بازیکن انسانی یا ربات قابل استفاده‌اند.

مسیرها و مختصات برد مار و پله در `src/utils/snakesAndLadders.ts` تعریف شده‌اند و بین منطق بازی، رسم برد و انیمیشن مشترک‌اند.

## اجرا

پروژه با React و Vite اجرا می‌شود:

```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار و پیش‌نمایش آن:

```bash
npm run build
npm run start
```
